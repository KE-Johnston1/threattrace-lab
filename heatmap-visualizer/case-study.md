# Case Study: SSH Brute-Force Activity Visualised

## Purpose

The heatmap visualizer provides a visual investigation aid for the ThreatTrace SOC pipeline. It converts structured SSH authentication telemetry into a time-based activity view so an analyst can quickly identify bursts of suspicious activity.

This module uses the same synthetic telemetry generated by `../offensive-simulation/brute_force_simulator.py` and consumed by the detection engine.

## Scenario

ThreatTrace generates a controlled SSH authentication scenario containing:

- 12 failed SSH authentication attempts
- repeated targeting of the `admin` account
- a successful `admin` authentication from the same source
- source IP `10.10.10.50`
- destination IP `10.10.10.10`
- destination port `22`

The visualisation helps an analyst see the concentration of authentication activity over time.

## Detection Workflow

```text
Synthetic SSH Telemetry
          ↓
     Heatmap View
          ↓
  Activity Concentration
          ↓
   Detection / Triage
          ↓
 IOC + Timeline Investigation
```

### 1. Log Capture

The simulator creates structured SSH authentication events locally. No real authentication attempts are performed.

### 2. Heatmap Visualisation

`heatmap_builder.py` groups events into one-minute UTC buckets and displays event counts by event type. A concentrated burst of `SSH_AUTH_FAILURE` events makes the authentication pattern easier to recognise.

Example command:

```bash
python heatmap_builder.py --log ../offensive-simulation/brute_force.log --save ssh-activity-heatmap.png
```

### 3. Anomaly Detection

`anomaly_detector.py` identifies source IPs generating unusually high event volumes. The threshold is configurable from the command line.

```bash
python anomaly_detector.py --log ../offensive-simulation/brute_force.log --threshold 5
```

### 4. Activity Pattern Matching

`signature_matcher.py` identifies defensive patterns such as repeated SSH authentication failures and a failure-to-success pivot.

```bash
python signature_matcher.py --log ../offensive-simulation/brute_force.log
```

## Analyst Interpretation

The heatmap is **supporting evidence**, not the detection itself. A visual concentration of events does not prove malicious activity. The analyst correlates the visual pattern with the detection rule, source IP, account, timeline and successful authentication event.

For this scenario, the combined evidence supports escalation to `SSH-BRUTE-001` with HIGH severity because repeated failures are followed by successful authentication from the same source.

## Why This Matters in a SOC

Visualisation can help analysts identify activity bursts and prioritise investigation. It is particularly useful when large volumes of telemetry make individual events difficult to interpret.

The visualizer therefore sits alongside, rather than replaces, the deterministic detection engine.

## Safety

All telemetry is synthetic and intended for defensive learning and portfolio demonstration. The visualizer does not connect to external hosts or perform network activity.
